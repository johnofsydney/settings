# Home machine

Personal Pro plan — the weekly allowance has to last, so prefer throughput over fidelity:

- `/clear` between tasks instead of letting one session sprawl. Same context loss as
  compaction, none of the cost.
- Read surgically — `Grep`, or `Read` with `offset`/`limit`. A big file rides along in
  every later turn of the session.
- Batch follow-ups into one message.

Everything else is in the shared core. Work context lives in `context-work.md` and is
deliberately absent here. See `claude/README.md`.
